# RecSys-Course-Competition

Этот проект был выполнен в рамках соревнования по рекомендательным системам на платформе [ods.ai](https://ods.ai/). Основная задача заключалась в построении рекомендательной системы, которая могла бы эффективно предсказывать предпочтения пользователей на основе их взаимодействий с различными элементами

## Использованные данные

Данные для проекта были взяты с платформы [ods.ai](https://ods.ai/). Они включали в себя:

- **Метаданные айтемов**: Информация о товарах
- **Метаданные пользователей**: Информация о пользователях
- **История взаимодействий**: Данные о взаимодействиях пользователей с элементами (факт просмотра)

## Использованные методы и модели

Для решения задачи были использованы следующие подходы и модели:

### 1. Item2Vec
Модель, которая обучает векторные представления для элементов. Эмбеддинги элементов использовались для вычисления сходства между элементами и генерации рекомендаций

### 2. User2Vec
Аналогично Item2Vec, но обучает векторные представления для пользователей на основе их взаимодействий с элементами, а также собственных фичей

### 3. История пользователя
Использование истории взаимодействий пользователей для улучшения рекомендаций

## Метрика качества

Для оценки качества рекомендаций использовалась метрика **MAP@10K**

## Результаты

Для небольшого подмножества пользователей была получена метрика **MAP@10K = 0.1875**
